## English

This unofficial study pack covers Part A of Thailand’s 2026 diplomat recruitment exam. It includes 12 practice sets from foundation to advanced, three 40-question mock exams drawn from the practice bank, and the original recap and exam-day cards. The HTML file runs locally without installation.
